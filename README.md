# Foresee

Auto-insurance quote estimates for Claude. Ask in plain English — e.g. *"how much
would car insurance cost for a 2022 Camry in NY?"* — and get a per-carrier monthly
point estimate with a confidence interval.

## Add to Claude (recommended)

**[→ Add Foresee to Claude](https://claude.ai/customize/connectors?modal=add-custom-connector&connectorName=Foresee&connectorUrl=https%3A%2F%2Fforesee-mcp-1026846013023.us-central1.run.app%2Fmcp)**

Or scan on your phone:

## Use in Claude Code

Prefer the terminal? Install as a plugin:

```bash
/plugin marketplace add Foresee-Tech/foresee
/plugin install foresee@foresee
```

On enable, Claude prompts for an API key.
