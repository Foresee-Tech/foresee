# Foresee

Home and auto insurance quote estimates for Claude. Ask in plain English — e.g.
*"how much would car insurance cost for a 2022 Camry in NY?"* — and get a
per-carrier monthly point estimate with a confidence interval.

## Use in Claude Code

Prefer the terminal? Install as a plugin:

```bash
/plugin marketplace add Foresee-Tech/foresee
/plugin install foresee@foresee
```

On enable, Claude prompts for an API key.
