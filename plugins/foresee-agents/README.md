# Foresee Agents

Foresee enables AI to shop for home and auto insurance.
This is the `foresee` plugin plus **live carrier quotes**: Foresee agents
complete the carriers' own online quote flows and read back the page-printed
premium, so the instant estimate comes with proof it holds up on the
carrier's site.

Live submissions run only with the user's explicit, in-chat consent, and no
sign-in is needed. If you only want instant estimates, use the base
`foresee` plugin.

## Install

```bash
/plugin marketplace add Foresee-Tech/foresee
/plugin install foresee-agents@foresee
```

Or point any MCP client at:

```
https://agents.go-foresee.com/mcp
```
